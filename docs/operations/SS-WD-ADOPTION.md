# SS-WD Adoption

Authoritative local reference: `D:\work\SS-WD` (separate repository; do not change its origin or vendor it here).

Adopted principles:

- Founder/Team Leader communicates with the Chief of Staff.
- Research first, MVP first, smallest adequate architecture.
- Worker selection is separate from runtime/workspace selection.
- Delegate only genuinely independent work; one writer per workspace/scope.
- Visible/inspectable workers, explicit identity, bounded monitoring, completion sentinel when needed.
- Worker “done” text is not acceptance; inspect diff, tests, runtime and artifacts.
- Unknown identity, ownership, delivery or cleanup fails closed.
- Preserve private timelines/transcripts locally; never push them.

This repository does not copy SS-WD runtime source or claim that an agent runtime is built in. Member clones and profile rules are operating boundaries; actual worker processes are launched only when requested and allowed by competition rules.
