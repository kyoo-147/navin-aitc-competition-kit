## Change protocol

1. Worker stops and returns a change proposal.
2. Captain explains impact in Lavish when the change is material.
3. User approves or rejects.
4. Captain updates affected source-of-truth files and artifacts.
5. Captain creates a new project lock and notifies every affected lane.
