# Working Style

- Official-source research first; preserve URLs and retrieval dates.
- Build the smallest runnable solution after the challenge is known.
- Plan briefly, then execute in independently verifiable slices.
- Prefer cheap authorized models for routine work; escalate only when evidence warrants it.
- Track budget, latency, output quality, and retries.
- Test behavior, not prose. Keep submission staging deterministic.
- Parallelize only independent scopes; otherwise work sequentially.
- Never accept worker completion text without diff/test/runtime evidence.
- Keep communication concise: changes, evidence, blockers, risks, next action.
