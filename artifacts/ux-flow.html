UX FLOW LAVISH B

Clone một lần. Cấu hình rõ ràng. Không chạm secret.

Đây là trải nghiệm setup dành cho teammate trên máy Windows mới. Mỗi bước phải cho biết điều gì đã làm, điều gì chưa làm và hành động nào chỉ con người được phép thực hiện.

Happy path - khoảng 5 bước

  • Clone private kit
  • Bootstrap
  • Nhập secrets
  • Doctor
  • Clone official repo
  • BTC preflight
01

Clone

git clone <private-kit>

Nếu GitHub auth thiếu, dừng và hướng dẫn login. Không bypass quyền repo.

02

Bootstrap

.\setup\bootstrap.ps1

Hiện plan, backup destinations, cài tools/skills, render config và không hỏi secret.

03

User action

Chỉ người dùng nhập key vào ignored .env hoặc process environment.

Không paste key vào prompt, Git hay screenshot.
04

Doctor

.\setup\doctor.ps1

PASS/BLOCKED cho versions, files, hashes, hooks, browser safety và secret placeholders.

05

Official clone

Clone repo BTC riêng. Organizer files ở root; toàn bộ team output ở chung-khao/.

06

Competition-ready gate

Gateway → provider proof → AI Log local → submit 202 → readback → Orca preflight.

Modes

Install

Máy mới, tạo cấu hình portable từ template.

Update

Nâng kit, diff trước khi thay, giữ secrets và local state.

Doctor

Read-only, không sửa máy.

Rollback

Khôi phục allowlisted config từ backup.

Failure states phải rõ

BLOCKED
Prerequisite hoặc repo identity sai.
USER ACTION REQUIRED
Login, key hoặc approval.
PRESERVED
Existing config không bị ghi đè.
READY
Doctor và competition gates pass.
